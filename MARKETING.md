# Godhuli: search & growth playbook

This playbook covers how Godhuli gets found on the VS Code Marketplace, Open VSX and Google, and how it turns visitors into installs. It isn't shipped in the `.vsix`.

## 1. The honest picture

- **The bare query "theme" is owned by giants.** One Dark Pro, Dracula, GitHub Theme, Material Theme and Monokai Pro have millions of installs and years of ratings. A new theme won't outrank them on "theme" or "dark theme" in month one.
- **Ranking isn't documented.** Microsoft doesn't publish the Marketplace ranking formula. What's observable:
  - Text relevance in the display name, description and tags.
  - Then popularity: installs, ratings and trending.
  - Exact name and ID matches get priority (this is also how Cursor's Open VSX search works).
- **So the strategy is long-tail first.** Win specific searches with clear intent ("warm theme", "eye comfort", "OLED", "low contrast", "colorblind", "gruvbox alternative"). Those bring early installs and ratings, which then lift the broad terms.

## 3. Keyword strategy

| Tier | Keywords | Realistic? | Where they live |
|---|---|---|---|
| Head | theme, color theme | Not at launch | displayName ("Theme"), tags |
| Mid | dark theme, light theme, warm theme, night theme | After about 1–5k installs | description, tags, H1 |
| **Long-tail (primary)** | eye comfort, eye strain, low blue light, low contrast, OLED theme, colorblind theme, borderless, sepia/paper light theme, theme for long coding sessions | **Yes, from day one** | displayName, description, tags, "Why", FAQ |
| Alternatives | gruvbox / nord / tokyo night / everforest **alternative** | Yes, via Google and blogs | README "Coming from another theme?" table, blog posts |
| Brand | godhuli, dusk | Always #1 | name, tags |

Rules:
- **Don't put competitor names in Marketplace tags.** It reads as keyword stuffing. Mention them only in honest comparison text.
- **Keep to 30 tags.** `package.json` already has exactly 30.
- **Put keywords first.** The first ~35 characters of `displayName` and the first ~140 of `description` are what show in the Extensions list and in Google snippets.

## 4. Listing conversion (installs per visit)

Ranked by impact:
1. **Screenshots** (generated by `npm run screenshots`; keep them current). This is the biggest lever for a theme. Add a hero image plus one per flavor, showing real TSX/Python code at 1280–1600 px wide in PNG. Use descriptive alt text ("Godhuli Dark theme in VS Code showing a React TypeScript file").
2. **Icon.** Done: `images/icon.png`, rendered from the brief below.
3. **Early ratings.** Ask 5–10 friends or colleagues who actually use it to leave an honest rating in the first week. Never buy reviews or swap fake ones; that violates Marketplace terms. Reply to every review.
4. **Freshness.** Small, real updates every 2–6 weeks (token fixes, new language scopes) keep "Last updated" recent. Write a human CHANGELOG.
5. **Badges.** The README badges (installs, rating) work as social proof once the numbers grow.

**Icon design (implemented in `scripts/screenshots.mjs`):** an ember half-sun (`#E9AC72`) setting behind a flat umber horizon band (`#24211F` on `#1B1918`). Three short teal (`#87CDC0`) horizontal strokes, the "cow dust", drift across the sun. Flat and geometric, legible at 16 px. 

## 5. Off-Marketplace channels

| Channel | Action | Why |
|---|---|---|
| **GitHub repo** | Description: *"Warm, eye-comfort VS Code theme. Dark, OLED Night, Mist & Light. Colorblind-safe, borderless."* Topics: `vscode-theme`, `vscode`, `theme`, `dark-theme`, `light-theme`, `color-scheme`, `eye-comfort`, `accessibility`, `colorblind`, `oled`, `low-contrast`, `warm`, `vscode-extension`, `syntax-highlighting`, `apca` | GitHub topic pages and Google index these |
| **Open VSX** | Publish every release (see PUBLISHING.md) | Cursor, VSCodium and Windsurf users can only find it there |
| **vscodethemes.com** | It indexes Marketplace themes automatically, with live previews. Check the listing a few days after publishing | A high-intent theme browsing site |
| **Reddit r/vscode** | One post: a screenshot gallery plus the "why" (eye comfort, measured contrast). Answer comments | The biggest single launch spike for themes |
| **dev.to / Hashnode / blog** | "How I built an eye-comfort VS Code theme with APCA and colorblind simulation." Link to the Marketplace | Ranks on Google for "eye comfort vscode theme"; durable backlinks |
| **Hacker News "Show HN"** | Lead with the engineering (token pipeline, APCA gate) | Technical audience, good backlinks |
| **Product Hunt** | Optional, with a gallery of the four flavors | A one-day spike |
| **awesome-vscode lists** | Send PRs adding Godhuli under Themes | Long-term discovery and backlinks |
| **X / Bluesky / Mastodon** | Before-and-after screenshots, tagged `#vscode` | Visual content spreads |

## 6. 30-day launch checklist

- [ ] Day 0: rerun `npm run screenshots`, push `images/`, real `publisher` and repo URLs, GitHub topics, then publish to the Marketplace and Open VSX
- [ ] Day 1: install from both registries on a clean profile; confirm the badges render
- [ ] Day 2: Reddit r/vscode post
- [ ] Day 3–5: dev.to / blog article; Show HN
- [ ] Day 7: ask early users for honest ratings; reply to all feedback
- [ ] Day 10: check vscodethemes.com; send awesome-list PRs
- [ ] Day 14: ship 0.2.x with fixes from feedback (freshness)
- [ ] Day 30: review the metrics; double down on the best channel
