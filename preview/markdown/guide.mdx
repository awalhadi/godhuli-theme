# {meta.title}

Refunds in **Godhuli Shop** move an order from `paid` to `refunded`. This guide
walks through the API and the dashboard flow.

<Callout type="info" title="Before you start">
  You need the `orders:write` scope. Ask an admin if the **Refund** button is
  greyed out.
</Callout>

## Order lifecycle

<OrderTimeline steps={["pending", "paid", "shipped", "refunded"]} highlight={3} />

The sample order totals {formatMoney(sampleOrder.total, sampleOrder.currency)},
and has {sampleOrder.total > 1000 ? "high" : "normal"} refund priority.

## Issuing a refund

<Tabs defaultValue="api">
  <Tab value="api" label="API">

```ts
await shop.orders.refund(10012, { amount: 1540, reason: "damaged_item" });
```

  </Tab>
  <Tab value="dashboard" label="Dashboard">
    1. Open **Orders** → *#10012*
    2. Click **Refund** and confirm
  </Tab>
</Tabs>

<Callout type="warning">
  Partial refunds are not yet supported. Track progress in{" "}

</Callout>
